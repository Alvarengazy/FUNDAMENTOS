## 👋 About the project

Welcome to **Java Learning Library**! This repository documents my journey learning Java, starting with the fundamentals and growing step by step.

This is a hands-on learning project: I write the examples myself, run them, review the results, and document what I understand. The goal is not just to make code run — it is to understand **why it works** and how to write code that is clear and maintainable.

## 🎯 What you will find here

- 📘 Explanations of core Java concepts.
- 💻 Small examples that can be tested independently.
- 🧠 Notes made while studying.
- 🔁 Two approaches when useful:
  - **Method 1:** an explicit, easy-to-follow version.
  - **Method 2:** a more concise alternative that practices direct returns and reuse when appropriate.

> **Learning principle:** concise code is not automatically better code. Readability and maintainability matter.

## 📚 Current topics

| Topic | What I am learning |
|---|---|
| Primitive types | `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean` |
| Text | `String`, text concatenation |
| Variables & literals | Declaring values and understanding literals |
| Methods | `static`, parameters, return types, `return`, method calls |
| Console output | Displaying results with `System.out.println()` |

**Note:** `String` is essential in Java, but it is a class — not one of Java's eight primitive types.

## 🧪 How I use this library

1. Read the concept.
2. Type the example manually instead of only copying it.
3. Run the program and inspect the output.
4. Try a variation independently.
5. Review mistakes and update the notes.

## 🧭 Learning roadmap

- [x] Begin documenting Java fundamentals
- [x] Practice the eight primitive types
- [x] Practice basic `String` usage
- [x] Explore methods and return values
- [ ] Review and refine the fundamentals
- [ ] Continue with the next Java concepts
- [ ] Build small projects as my skills grow

## 👋 Sobre o projeto

Boas-vindas à **Java Learning Library**! Este repositório documenta minha jornada de aprendizado em Java, começando pelos fundamentos e avançando passo a passo.

Este é um projeto de aprendizado prático: escrevo os exemplos por conta própria, executo o código, analiso os resultados e documento o que compreendi. O objetivo não é apenas fazer o código funcionar — é entender **por que ele funciona** e como escrever código claro e fácil de manter.

## 🎯 O que você encontrará aqui

- 📘 Explicações dos conceitos fundamentais de Java.
- 💻 Exemplos pequenos que podem ser testados individualmente.
- 🧠 Anotações feitas durante os estudos.
- 🔁 Duas abordagens quando isso for útil:
  - **Método 1:** uma versão explícita e fácil de acompanhar.
  - **Método 2:** uma alternativa mais concisa para praticar retornos diretos e reutilização quando fizer sentido.

> **Princípio de aprendizado:** código compacto não é automaticamente código melhor. Legibilidade e manutenção também importam.

## 📚 Conteúdos atuais
